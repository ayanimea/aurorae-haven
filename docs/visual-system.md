# Schedule – Visual System Specification

## Surface Model

The Schedule page uses a single unified background surface.

The starfield is the only base surface.
All schedule components must remain transparent unless explicitly required.

The timegrid must not introduce opaque containers.

---

## Atmospheric Time Cues

Time-of-day modulation is achieved through ultra-subtle vertical tinting.

Rules:

- Opacity must remain below 0.20.
- Transitions must be smooth.
- Horizontal bands must not be visually identifiable.

Atmosphere is perceptual, not graphic.

---

## Event Card Physics

Event cards are luminous objects floating above space.

They must:

- Use gradient interior.
- Use translucent backgrounds.
- Avoid solid borders.
- Use diffused shadows (large blur radius).
- Avoid sharp neon glow.

Cards should feel like light diffusing outward, not UI blocks with outlines.

---

## Glow Rule

Glow is allowed only when:

- It enhances atmospheric cohesion.
- It is diffused and soft.
- It does not introduce sharp luminous edges.

No high-contrast glow strokes.

---

## Design Principle

The UI should feel atmospheric and cohesive.

If an effect is clearly visible as an effect,
it is too strong.
